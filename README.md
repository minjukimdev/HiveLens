# HiveLens

HiveLens enables real-time, distributed data processing and auto-scaling through management and optimized task allocation on the underlying processor.

The key benefits of using HiveLens include:

- HiveLens enables real-time, distributed data
- processing and auto-scaling through management
- and optimized task allocation on

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/HiveLens.git`
2. `cd HiveLens`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure HiveLens, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
